# Danger-level push notifications via OneSignal (v3)

This change adds push notification infrastructure for water-level danger alerts. When a station's alert level transitions from below 3 to exactly 3, the Convex backend schedules a OneSignal broadcast to all push subscribers, gated by a 1-hour per-station cooldown. The frontend provides a bell icon that opens a dialog for toggling push subscription via the OneSignal browser SDK. All four v1 issues and both v2 issues have been addressed.

Watch for: no remaining blocking concerns.

**Verdict**: APPROVED

## High-level view

The notification flow is now sound: `waterLevelUpdater` detects a rising transition into danger, schedules `notifyDangerForStation`, which checks per-station cooldown before broadcasting. After a successful send, `recordStationCooldown` writes a station-level cooldown entry with `userId` omitted, ensuring the cooldown engages regardless of whether anyone has favorited the station. The broadcast-to-all-subscribers delivery model is explicitly documented as intentional for the current auth-less state, with the favorites table positioned as scaffolding for future per-user targeting.
